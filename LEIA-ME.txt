# Painel de Ocorrências (Protótipo)

## Como abrir no celular ou computador

1. Extraia o ZIP inteiro (não abra somente o index.html de dentro do visualizador do ZIP).
2. Mantenha `index.html`, `style.css` e `app.js` juntos na mesma pasta.
3. Abra o `index.html` no Chrome, Edge ou Firefox.

## Estrutura

- `index.html`: painel principal
- `style.css`: aparência e adaptação para telas menores
- `app.js`: relógio e simulação de ocorrências

## Correções

- Arquivos principais diretamente na raiz do ZIP para facilitar a extração.
- Referências de CSS e JavaScript com versão para evitar cache antigo.
- Layout responsivo para celular e computador.
- Mantidos os cartões das duas entradas e o botão de simular ocorrência.

## Importante

> Este pacote é um protótipo demonstrativo. Não está conectado a câmeras, sensores, controle de acesso, banco de dados, Cloudflare ou WhatsApp. As ocorrências são fictícias. Não use para decisões reais de liberação ou retirada de alunos. Uma implantação real exige integração, testes, controle de acesso, validação de privacidade/LGPD e conferência humana.
